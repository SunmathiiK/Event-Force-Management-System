# Event-Force-Management-System

Salesforce CRM Implementation – Naan Mudhalvan
EventForce Management System is a Salesforce-based CRM solution designed to centralize and streamline event planning and management operations.

📌 Project Overview
The system manages:

Events
Clients
Venues
Vendors
Event-Vendor Assignments
Feedback
Event Cancellations
It uses Salesforce automation, Apex, security controls, reports, and dashboards to improve event coordination and reduce manual processes.

🎯 Objectives
Centralize event, client, venue, vendor and feedback information
Streamline event booking and venue reservation
Prevent venue double booking
Automate event reminders
Manage cancellation approvals
Improve vendor and event coordination
Provide reports and dashboards for operational visibility
Maintain secure and controlled access
🛠️ Technology Stack
Salesforce CRM / Developer Edition
Salesforce Lightning App
Salesforce Custom Objects
Salesforce Flows
Validation Rules
Formula Fields
Approval Processes
Apex Classes
Apex Triggers
Batch Apex
Scheduled Apex
Reports & Dashboards
Profiles, Roles, Permission Sets & Sharing Rules
⚙️ Key Features
Event Management
Create and manage event details including event type, date, status and budget.

Venue Management
Manage venue availability and prevent double booking using Apex logic.

Vendor Management
Assign multiple vendors to events using the EventVendor junction object.

Automated Reminders
A 3-Day Reminder Flow sends reminders for confirmed events.

Cancellation Approval
Cancellation requests are processed through a Salesforce Approval Process.

Security
Profiles, Roles, Permission Sets, Sharing Rules and Organization-Wide Defaults provide controlled access.

Reports & Dashboards
Reports and dashboards provide visibility into upcoming events, vendor activities and operational performance.
